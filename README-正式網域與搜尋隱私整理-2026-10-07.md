# 自然大叔｜顧客滿意度調查｜正式網域與搜尋隱私整理

日期：2026-10-07

## 本次修改

- 正式網址統一為 `https://survey.naturaluncle.com/`。
- 問卷首頁補上正式 canonical、Open Graph、Twitter 分享資訊。
- 問卷首頁「前往官方網站」改為 `https://naturaluncle.com/`。
- 感謝頁「回到自然大叔官方網站」改為 `https://naturaluncle.com/`。
- 問卷首頁、感謝頁、通知設定頁加入 `noindex, nofollow, noarchive`。
- 新增 `robots.txt`，全站不提供搜尋引擎爬取。
- `netlify.toml` 加入 `X-Robots-Tag`，包含一般頁面、API 與 Netlify Functions。
- 本系統不建立 `sitemap.xml`，也不需要提交 Sitemap 到 Google Search Console。
- 原有問卷送出、Brevo Email、LINE 推播、Netlify Blobs 通知設定功能未改動。

## 為什麼不讓 Google 收錄？

本頁是服務完成後提供給顧客填寫的回饋問卷，而不是一般行銷內容。避免被搜尋引擎帶入非顧客流量、假填答或機器人填答，比讓它出現在 Google 搜尋結果更合適。

## 重要安全提醒

請確認 Netlify 環境變數已設定 `NOTIFICATION_SETTINGS_TOKEN`。原系統在沒有設定這個值時，通知設定 API 不會要求 Token；設定後可避免未授權的人修改 Email / LINE 通知開關。
